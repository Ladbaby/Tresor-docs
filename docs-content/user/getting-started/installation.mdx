# 📦 Installation

Tresor is distributed as a single compiled Go binary with no external dependencies. Build it from source to get started.

## Prerequisites

- 🐹 **Go 1.26+** — required for compilation
- 📝 A YAML config file with your provider API keys (see below)

## 🔨 Building from Source

<Tabs>
  <TabItem value="linux" label="Linux">
    ```bash
    go build -o tresor .
    ```
  </TabItem>
  <TabItem value="macos" label="macOS">
    ```bash
    go build -o tresor .
    ```
  </TabItem>
  <TabItem value="windows" label="Windows">
    ```bash
    go build -o tresor.exe .
    ```
  </TabItem>
</Tabs>

The compiled binary has no runtime dependencies — it's a single executable that includes the daemon, CLI, web UI, and SQLite database engine.

## 🚀 Quick Start

### 1️⃣ Create a Config File

Copy the example configuration and customize it:

```bash
cp config.example.yaml config.yaml
```

Edit `config.yaml` to add your provider API keys at minimum:

```yaml
bind_addr: "127.0.0.1:8080"
db_path: "./tresor.db"

downstreams:
  - id: openai
    name: OpenAI
    base_url: https://api.openai.com/v1
    api_key: sk-proj-...          # Replace with your API key
    output_model_ids:
      - gpt-4o
      - gpt-4o-mini

  - id: anthropic
    name: Anthropic
    base_url: https://api.anthropic.com
    api_key: sk-ant-...           # Replace with your API key
    output_model_ids:
      - claude-sonnet-4-20250514
```

### 2️⃣ Start the Daemon

<Tabs>
  <TabItem value="default" label="Default config">
    ```bash
    ./tresor run
    ```
    This auto-detects `config.yaml` in the current directory or `~/.tresor.yaml`.
  </TabItem>
  <TabItem value="explicit" label="Explicit path">
    ```bash
    ./tresor run --config /path/to/config.yaml
    ```
  </TabItem>
</Tabs>

The daemon starts listening on the configured `bind_addr`. The proxy and admin API are available on this address.

### 3️⃣ Point Your Application

Configure your application's LLM client to use Tresor as the endpoint:

```
base_url: http://127.0.0.1:8080
```

Any request sent to Tresor is intercepted, routed to the appropriate downstream, and the response is returned — all transparently.

### 4️⃣ Open the Web UI

Navigate to `http://127.0.0.1:8080` in your browser to access the embedded dashboard for managing downstreams, rules, aliases, and settings visually.

## 📂 Config File Locations

Tresor auto-detects the config file in this order:

1. Path specified by `--config` flag
2. `./config.yaml` in the current working directory
3. `$HOME/.tresor.yaml` in your home directory

## ℹ️ Version Info

Check the compiled binary's version:

```bash
./tresor version
```

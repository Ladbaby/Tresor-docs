# MiniMax

[[official website (China)]](https://platform.minimaxi.com/) [[official website (International)]](https://platform.minimax.io/)

MiniMax models can be added to Tresor via your token plan subscription, or, via the pay-as-you-go API.
They are charged separately, and normal users are likely to use the token plan subscription way.

Pay-as-you-go API keys and M Plan Subscription Keys are separate.

<Tabs>
  <TabItem value="web" label="Web UI" default>
    Web UI is more intuitive, but requires more manual operations.

    In the "Downstreams" tab:

    - Click <kbd>+ Add Provider</kbd> if MiniMax is not already listed.
    - Enter `MiniMax` or any name you like.
    - Under "API Formats", select <kbd>OpenAI</kbd>, <kbd>OpenAI Responses</kbd>, and <kbd>Anthropic</kbd>.
    - Under "Authentication", select <kbd>API key</kbd> and enter a key created under "API Key" on the official website.
    - Under "API Host", choose one of:
        - China: `https://api.minimaxi.com`
        - International: `https://api.minimax.io`
    - Click <kbd>Advanced</kbd>. Under "Per-format URLs", set the Anthropic entry to one of:
        - China: `https://api.minimaxi.com/anthropic`
        - International: `https://api.minimax.io/anthropic`
    - Under "Models", click <kbd>Fetch Models</kbd> and add the models you need.
  </TabItem>
  <TabItem value="config" label="config.yaml">
    Editing YAML is less intuitive, but requires fewer manual operations.

    Replace `YOUR-MINIMAX-API-KEY` with your API key. The model ID below follows Tresor's example configuration; confirm it is available on your platform or replace it with one from your console.

    ```yaml title="~/.config/tresor/config.yaml"
    # Other settings omitted. Add this entry to your existing downstreams list.
    downstreams:
      - id: minimax
        name: MiniMax
        base_url: https://api.minimax.io
        api_formats:
          - openai
          - openai_responses
          - anthropic
        output_model_ids:
          - MiniMax-M3
        is_enabled: true
        auth:
          type: api_key
          api_key: YOUR-MINIMAX-API-KEY
        format_urls:
          anthropic: https://api.minimax.io/anthropic
    ```

    Restart Tresor to apply the YAML changes.
  </TabItem>
</Tabs>


Done! Clients accessing Tresor can now use your configured MiniMax models.

# Xiaomi (MiMo)

[[official website]](https://platform.xiaomimimo.com/)

MiMo models can be added to Tresor via your [token plan subscription](https://platform.xiaomimimo.com/token-plan), or, via the [pay-as-you-go API](https://mimo.mi.com/docs/en-US/price/pay-as-you-go).
They are charged separately, and normal users are likely to use the token plan subscription way.

> WARNING: As of 2026.10.31, the cache hit rate of Xiaomi MiMo is not stable, where some random requests will get abnormally low rate. The problem is likely caused by Xiaomi instead of Tresor.

<Tabs>
  <TabItem value="web" label="Web UI" default>
    Web UI is more intuitive, but requires more manual operations.

    In the "Downstreams" tab:

    - Click <kbd>+ Add Provider</kbd> if Xiaomi is not already listed.
    - Enter `Xiaomi MiMo` or any name you like.
    - Under "API Formats", select <kbd>OpenAI</kbd>, <kbd>OpenAI Responses</kbd>, and <kbd>Anthropic</kbd>.
    - Under "Authentication", select <kbd>API key</kbd> and enter a key from [MiMo Open Platform](https://platform.xiaomimimo.com/).
    - Under "API Host", choose one of:
        - Token plan:
            - China: `https://token-plan-cn.xiaomimimo.com`
            - Singapore: `https://token-plan-sgp.xiaomimimo.com`
            - Europe: `https://token-plan-ams.xiaomimimo.com`
        - Pay-as-you-go API: `https://api.xiaomimimo.com`
    - Click <kbd>Advanced</kbd>. Under "Per-format URLs", set the Anthropic entry to one of:
        - Token plan:
            - China: `https://token-plan-cn.xiaomimimo.com/anthropic`
            - Singapore: `https://token-plan-sgp.xiaomimimo.com/anthropic`
            - Europe: `https://token-plan-ams.xiaomimimo.com/anthropic`
        - Pay-as-you-go API: `https://api.xiaomimimo.com/anthropic`
    - Under "Models", click <kbd>Fetch Models</kbd> and add the models you need.
  </TabItem>
  <TabItem value="config" label="config.yaml">
    Editing YAML is less intuitive, but requires fewer manual operations.

    Replace `YOUR-MIMO-API-KEY` with your API key and `YOUR-MIMO-MODEL-ID` with an exact model ID from your console.

    ```yaml title="~/.config/tresor/config.yaml"
    # Other settings omitted. Add this entry to your existing downstreams list.
    downstreams:
      - id: mimo
        name: Xiaomi MiMo
        base_url: https://token-plan-cn.xiaomimimo.com # choose one of: Token plan: China: `https://token-plan-cn.xiaomimimo.com`; Singapore: `https://token-plan-sgp.xiaomimimo.com`; Europe: `https://token-plan-ams.xiaomimimo.com`; Pay-as-you-go API: `https://api.xiaomimimo.com`
        api_formats:
          - openai
          - openai_responses
          - anthropic
        output_model_ids:
          - YOUR-MIMO-MODEL-ID
        is_enabled: true
        auth:
          type: api_key
          api_key: YOUR-MIMO-API-KEY
        format_urls:
          anthropic: https://token-plan-cn.xiaomimimo.com/anthropic # choose one of: Token plan: China: `https://token-plan-cn.xiaomimimo.com/anthropic`; Singapore: `https://token-plan-sgp.xiaomimimo.com/anthropic`; Europe: `https://token-plan-ams.xiaomimimo.com/anthropic`; Pay-as-you-go API: `https://api.xiaomimimo.com/anthropic`.
    ```

    Restart Tresor to apply the YAML changes.
  </TabItem>
</Tabs>

Done! Clients accessing Tresor can now use your configured MiMo models.

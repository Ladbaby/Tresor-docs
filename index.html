Key Features

🔄
Protocol Translation
Convert between OpenAI and Anthropic formats transparently.
⚡
Auto-Translation
Automatically inserts format converters based on downstream API type.
🛤️
Per-Path Routing
Route different API paths to different providers.
🏷️
Model Aliasing
Map one model name to another. Hot-switch backends without restarting.
🔌
Plugin Pipeline
Chain multiple transformers per rule.
🌐
Embedded Web UI
Manage everything from a browser dashboard — no separate frontend needed.
